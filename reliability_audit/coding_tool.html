Before you start

  1. Make a copy of audit_coder2.xlsx and name it audit_coder2_completed.xlsx. Keep the original untouched.
  2. Open this page in Chrome or Edge. Click Open audit_coder2_completed.xlsx and allow the page to edit the file when asked. Every choice you make is saved straight into that file.
  3. For each site, read the code on the left (the highlighted line is where the search term matched; code the first presigning call at or after it) and choose one code per question on the right. The rule for each code shows when you choose it; Codebook rules shows them all.
  4. When every row is complete, write the date in the notes of row A001 and send the file back.

Keys: ← → previous and next site, N next incomplete site (outside the notes box).

Code from the window and the codebook only. Do not use AI tools or look the repositories up online. In Safari or Firefox the page cannot save into the file: use Download updated file often, and replace your copy with it.
